# 💬 MERN Real-Time Chat App

A feature-rich, full-stack real-time messaging platform built with the MERN stack. This application allows users to communicate instantly, manage their profiles, and authenticate securely via an OTP system.

## 🚀 Key Features

* **Real-Time Communication:** Instant bi-directional messaging powered by **Socket.io**.
* **Secure OTP Auth:** Email-based authentication using **Nodemailer** for a passwordless experience.
* **Media Handling:** Seamless profile picture uploads and optimized storage via **Cloudinary**.
* **Responsive UI:** A modern, mobile-friendly design crafted with **Tailwind CSS** and **Framer Motion** for smooth animations.
* **State Management:** High-performance global state handling using **Zustand**.
* **Security:** **JWT-based** protected routes and secure **HTTP-only cookies** for session management.

---

## 🛠️ Tech Stack

### Frontend
* **Framework:** React.js
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **State Management:** Zustand
* **API Client:** Axios & Socket.io-client

### Backend
* **Runtime:** Node.js
* **Framework:** Express.js
* **Real-time:** Socket.io
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Services:** Cloudinary (Images), Nodemailer (Email Delivery)

## ⚙️ Quick Start

1. **Clone the repo:** `git clone <your-repo-link>`
2. **Backend:** Install dependencies in the server folder and set up your `.env` 
3. **Frontend:** Install dependencies in the client folder and set up `.env` 
4. **Run:** Use `npm run dev` in both terminals to start your development environment.
